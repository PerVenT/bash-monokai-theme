# bash-monokai-theme

A collection of Monokai color scheme themes for Bash shell.

[[img/5e513086cf370788664a353b66517ac08c4df40c.png]]

## Installation

To install the theme, add one of the following lines to your `~/.bashrc`:

```bash
# For Octagon variant
source /path/to/bash-monokai-theme/Monokai_octagon

# For monochrome variant
source /path/to/bash-monokai-theme/Monokai_monochrome
```

Replace `/path/to/bash-monokai-theme` with the actual path to this repository.

## Features

- Multi-line prompt with datetime, user@hostname, and current directory
- Git branch display
- Virtual environment indicator
- Kubernetes context display
- Docker context display
- Two color variants: Octagon (colorful) and Monochrome (grayscale)
